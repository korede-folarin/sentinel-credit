        How this is built

        A governed champion

        Calibrated XGBoost, 13 features, selected and promoted through a champion / challenger workflow with an automated evidence gate. One feature was removed because it leaked the outcome, a decision taken on validity even though it cost a little Gini.

        Verified, not assumed

        The browser model was converted to ONNX and checked against the Python champion before publishing: zero decisions changed across 41,604 customers. Re-run the check in your browser.

        Honest about scope

        A customer-level portfolio-risk model, not a validated application-time underwriting model. It returns a probability and a review recommendation, never an invented credit score or limit.

        Every decision on record

        Each consequential choice, including the mistakes found and fixed, is in the Engineering Decision Log.
